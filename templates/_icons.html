{% comment %} The icon set. Included once at the top of in base.html; every icon on the platform is a reference into this sprite. Why a sprite and not files: one inline block, zero extra requests, and the icons inherit currentColor so they take the colour of whatever they sit in. An per icon would be 16 requests and unstylable. Note there is no xmlns attribute. Inline SVG in an HTML5 document doesn't need one, and adding it would put an http:// URL in the markup — which our "no external references" test rightly objects to. House style, kept consistent so they read as one family: 24x24 box · stroke, never fill · 1.6 stroke · round caps and joins If you add an icon, match those or it will look like a guest. {% endcomment %}
